## 👋 Quem somos

Somos cinco estudantes que acreditam que tecnologia boa é a que resolve problemas reais das pessoas. Na **Global Solution 2026/2 (CitizenTech)**, criamos o **Acesso Já**: um quadro público em que o cidadão avisa sobre problemas da cidade, os vizinhos confirmam e o órgão responsável mostra o andamento para todos.
